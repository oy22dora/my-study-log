# 学習ログ

HTML/CSS/JavaScriptとlocalStorageだけで動く、毎日の集中度と学習メモを記録するアプリです。

日付ごとに「今日の集中度」と「今日の学習メモ」を保存できます。保存した記録はブラウザのlocalStorageに残るため、ページを閉じても同じブラウザで再度開けば学習の記録を見返せます。学習メモには、数学の復習や英単語、読書メモなどを書けます。氏名や学校名などの個人情報は入力しないでください。

このリポジトリは学習用アプリに育てるための土台として使います。

## デモの動かし方

`index.html` をブラウザで開くだけで使えます。ビルドやサーバー起動は不要です。

```text
my-study-log/
├── index.html
├── styles.css
├── app.js
├── README.md
└── LICENSE
```

## 機能

- 今日の日付を自動セット
- 集中度を5段階から選択
- 今日の学習メモを保存
- 日付ごとに1件の記録として保存
- 同じ日付で保存すると上書き
- 過去の学習記録の一覧表示
- 保存済みログの編集
- 保存済みログの削除
- 学習メモの検索
- 集中度で絞り込み
- 最近7件の集中度の流れを表示する波形グラフ

## 使用技術

- HTML
- CSS
- JavaScript
- localStorage

外部ライブラリは使っていません。

## localStorage

保存キーは `tiny-diary.entries.v1` です。

データは次のような配列で保存されます。

```json
[
  {
    "id": "example-id",
    "date": "2026-04-29",
    "mood": "happy",
    "note": "数学の二次方程式を復習。英単語を10個覚えた。",
    "createdAt": "2026-04-29T10:00:00.000Z",
    "updatedAt": "2026-04-29T10:00:00.000Z"
  }
]
```

## 集中度データ

集中度は次の5段階です。保存データとの互換性のため、JSON内の `mood` と各段階の値は従来の名前を使っています。

| 値 | 表示 | スコア |
| --- | --- | --- |
| `happy` | よく集中 | 5 |
| `calm` | 集中できた | 4 |
| `normal` | ふつう | 3 |
| `tired` | 少し難しい | 2 |
| `sad` | 集中しにくい | 1 |

集中度の波形グラフでは、最近7件の記録をこのスコアに変換して表示します。

## 教材で説明しやすい流れ

1. フォームから値を受け取る
2. JavaScriptの配列に学習データを追加する
3. `JSON.stringify` でlocalStorageへ保存する
4. `JSON.parse` でlocalStorageから読み込む
5. 配列をもとに学習記録の一覧と集中度グラフを再描画する
